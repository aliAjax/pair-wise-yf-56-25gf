# pair-wise-yf-56 网络安全事件响应作战室

## 源提示词摘要
值班人员接收告警，分析人员补充资产和影响范围，响应负责人批准隔离、封禁或恢复动作，法务和公关维护对外口径。系统展示实时事件时间线、子事件、审批、证据和责任人；高优先级动作双人确认，敏感内容按角色显示，并支持只读演示模式。

## 技术栈
Next.js 15 + TypeScript + App Router + shadcn/ui 本地组件 + Zustand + TanStack Query + React Hook Form + Zod + next-intl + date-fns + dnd-kit。

## 已实现闭环
- 主事件、子事件、处置动作和实时时间线。
- 子事件创建、动作审批、双人确认和执行状态流转。
- 角色权限控制、敏感内容遮蔽、只读演示模式。
- dnd-kit 调整处置优先级、TanStack Query 实时连接检查和 Zustand 持久化。

## 断网补传与对账（本迭代）
- **双时间戳**：事件保留发生时间 `at`，补传/到达时刻另记 `receivedAt`。实时流按收到顺序排列（补传事件发生再早也排在回网时刻）；对账台账把主事件时间线、审批记录、执行记录按发生时间归并排序，补传时刻单列不参与排序。
- **晚到事件作废旧审批**：补传事件标记为改变结论时，相关处置动作的有效审批整体失效并退回待确认，原审批记录保留（`invalidated`），重新审批另写新记录；无关动作不受影响。
- **补传幂等重试**：首次补传模拟部分事件写失败并逐条列出原因；重试整批重放，按事件 id 去重，只有没写进的几条落库，重复到达的不再记（计数展示）。
- **资产级隔离**：隔离按受影响资产逐个落地并逐资产记账，失败项（含原因、尝试次数）单独列出；重试只重试失败项，已隔离资产自动跳过；全部成功才置为已执行，否则为部分落地。
